Question

Differences Between Binomial and Binary Data The primary difference is that binary data represents the outcome of a single event (or “trial”) that has only two possible outcomes (e.g., success/failure, yes/no, 1/0). In contrast, binomial data represents the total number of successes in a fixed number of independent binary trials.

What Model Should You Fit to Binary Data? you should fit a logistic regression model. This is a type of Generalized Linear Model (GLM) that is specifically designed for binary outcomes. In R, this is done using the glm() function with the argument family = “binomial”.

This model uses a logit link function, logit(p)=log( 1−p/p), to connect the predictors to the probability of the outcome, ensuring that the predicted probabilities are always between 0 and 1

What Happens When You Fit a Normal Linear Model to Binary Data? Fitting a normal linear model (using lm() in R) to binary data is inappropriate and leads to Nonsensical Predictions: The model can predict probabilities less than 0 or greater than 1

Constant Variance (Homoscedasticity): Linear models assume the variance of the errors is constant. With binary data, the variance depends on the probability itself and is not constant(heteroscedasticity), which violates a core assumption of the model.

How to Interpret Coefficients from a Logistic Regression The coefficients (Estimate in the R summary) from a logistic regression are on the log-odds scale and are not directly interpretable as changes in probability. To interpret them, you must exponentiate the coefficient (e^β) to get an odds ratio.

For a continuous predictor (e.g., age): If the coefficient for age is β, then e^β is the odds ratio. This means for a one-year increase in age, the odds of the outcome (e.g., having the disease) are multiplied by a factor of e^β.

For a categorical predictor (e.g., SexM): If the coefficient for a male patient is β, then e^β is the odds ratio comparing males to the baseline category (females). The odds of the outcome for a male are e^β times the odds for a female.

1 Differences Between Count and Continuous Data

The primary difference between count and continuous data lies in the values they can take.

  • Count Data: Consists of non-negative integers (0, 1, 2, 3, …). It represents things that can be counted, like the number of items purchased by a customer or the number of children in a family. The values are discrete and have clear gaps between them.

  • Continuous Data: Can take any value within a given range. It represents measurements, like height, weight, or temperature. There are infinite possible values between any two points. For example, a person’s height can be 175 cm, 175.1 cm, or 175.11 cm.

2. What Model Should You Fit to Count Data?

For count data, the standard and most appropriate model is a Poisson model. This is a type of Generalized Linear Model (GLM) specifically designed for count outcomes.

The Poisson model is suitable because it assumes the data follows a Poisson distribution and uses a log link function to ensure that all predicted counts are non-negative. For data with more variability than the Poisson model assumes (a common issue called overdispersion), a quasipoisson model is a better choice.

Overdispersion means that there is more variability (or “scatter”) in your data than what your statistical model predicts. It’s a common issue when modeling count or proportion data.

4. How to Interpret Coefficients from a Poisson Model

The coefficients from a Poisson model are on a logarithmic scale, so they are not interpreted additively. To interpret them correctly, you must exponentiate the coefficient (eβ) to get a rate ratio or multiplicative factor.

  • For a categorical predictor (e.g., sexM): If the coefficient for males is β, then eβ is the rate ratio. For example, if eβ≈1.12, it means males are expected to have, on average, 1.12 times the count of females (or 12% more).

  • For a continuous predictor (e.g., visits): If the coefficient for visits is β, then for a one-unit increase in visits, the expected count is multiplied by a factor of eβ.
